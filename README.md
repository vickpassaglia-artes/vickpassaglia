# Vick Passaglia Artes
Landing page inicial da marca — **Criar • Ensinar • Compartilhar**.

Arquivos: `index.html` (conteúdo), `style.css` (visual responsivo) e `script.js` (menu e interações).

## Publicar no GitHub Pages
1. Crie um repositório público chamado `vick-passaglia-artes`.
2. Envie os três arquivos para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)` e salve.
6. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/vick-passaglia-artes/`.

A galeria ainda contém espaços gráficos provisórios. Substitua-os por fotos reais antes de divulgar. O formulário ainda não envia mensagens: precisa ser ligado a um e-mail/serviço de formulário.
